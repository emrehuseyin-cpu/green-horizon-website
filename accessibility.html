HOME // INCLUSION & DIGITAL ACCESS

Accessibility Statement

Ensuring universal, barrier-free digital access for all European youth and citizens in conformity with WCAG 2.1 AA guidelines.

Our Commitment

The Green Horizon consortium (Integrational e.V., IESA, and Asociația Empower Plus) is firmly dedicated to digital inclusion. In accordance with the values of the European Union’s Erasmus+ programme, this website is designed to ensure that everyone, regardless of physical ability, technological environment, or assistive tools, can explore our environmental resources and exhibitions.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA.

https://greenhorizonyou.eu is designed and tested to achieve WCAG 2.1 Level AA conformance, with several key components satisfying Level AAA criteria.

Key Accessibility Features Implemented

  • High-Contrast Color System: The dark aesthetic (#071411) uses text colors (#FFFFFF, #E2E8F0, #B7FF4A) that exceed WCAG 2.1 AA minimum contrast ratios (7:1 for headings and 4.8:1 for body copy).
  • Keyboard Navigation & Focus Indicators: All interactive components (links, buttons, exhibition items, dialogs) can be navigated using standard keyboard controls (Tab, Shift+Tab, Enter, Space, Escape, Arrows). Active focus states are clearly delineated with electric green outlines (:focus-visible).
  • Skip to Content Link: A direct skip-link is provided at the very top of each page for keyboard and screen reader users to bypass repetitive navigation.
  • Semantic Structure & Landmarks: Clean semantic HTML5 elements (<header>, <nav>, <main>, <section>, <article>, <footer>) and ARIA attributes provide consistent structure for assistive technologies.
  • Accessible 360° & Media Viewers: Interactive components, including the 360° virtual reality panorama viewer, provide accessible text labels, pause/rotate controls, and fallback descriptions.
  • Respect for User Preferences: Code architecture respects prefers-reduced-motion media queries to minimize or disable non-essential animations for users with vestibular sensitivities.

Feedback & Reporting Barriers

We welcome your feedback on the accessibility of the Green Horizon website. If you encounter any accessibility barriers, please inform our accessibility coordinator:

Email: accessibility@greenhorizonyou.eu
Subject: Accessibility Feedback — Green Horizon Website
We strive to respond to accessibility inquiries within 5 business days and provide alternative accessible formats where needed.
